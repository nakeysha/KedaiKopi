# Kereta Kopi – Kasir Digital

Kereta Kopi merupakan aplikasi kasir digital berbasis website yang dirancang untuk membantu proses pemesanan dan transaksi pada usaha kedai kopi.

## Fitur
- Halaman utama dan login
- Pemesanan menu minuman
- Pengelolaan keranjang pesanan
- Pembayaran tunai dan QRIS
- Struk transaksi
- Rekap transaksi
- Pengelolaan menu

## Teknologi
- HTML
- CSS
- JavaScript

## Cara Menjalankan
1. Download atau clone repository ini.
2. Buka folder proyek.
3. Jalankan file `index.html` melalui browser.

## Struktur Folder
- `index.html` – Struktur halaman website
- `styles.css` – Tampilan dan desain website
- `script.js` – Fungsi dan interaksi aplikasi
- `images/` – Gambar produk, logo, dan QRIS
